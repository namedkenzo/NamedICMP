Client applications and their Windows/Android distribution dependencies are maintained separately in https://github.com/namedkenzo/NamedClients. They are not bundled in this server source tree or Linux release archives.

namedICMP is original MIT-licensed application code. The source tree does not
vendor PingTunnel, gohome, 3x-ui or their generated protocol files.

The Go build imports `github.com/klauspost/compress/zstd`, pinned through
`go.mod` and `go.sum` to v1.20.3. Zstandard encoding/decoding is a general
compression dependency, not a VPN core. The compiled binary includes its
licensed implementation and applicable internal utility packages.

Source and license: https://github.com/klauspost/compress

The build also imports `golang.org/x/crypto/chacha20poly1305` v0.57.0 and
its `golang.org/x/sys` v0.48.0 dependency for optimized CPU/OS support.
Both are general-purpose Go libraries, not tunnel applications. AES/GCM
uses Go's standard library. Versions and checksums are pinned in go.mod/go.sum.

Source and licenses: https://cs.opensource.google/go/x/crypto and
https://cs.opensource.google/go/x/sys . Both use the Go Authors BSD license
reproduced separately below.
