namedICMP

پنل مدیریت کاربران و هستهٔ مستقل TCP/UDP over ICMP، نوشته‌شده با Go.

Version: "0.2.1-alpha"

با تم اختصاصی، حالت تیره/روشن، انیمیشن‌های سبک و رمزنگاری اختیاری.

«[!WARNING]
این پروژه از کد، باینری یا اینستالر PingTunnel و سایر پروژه‌ها استفاده نمی‌کند. قرارداد پیام‌های شبکه برای سازگاری حفظ شده، اما پیاده‌سازی کاملاً از نو نوشته شده است.»

⚡ نصب (One-Click Installation)

سریع‌ترین روش نصب، اجرای دستور زیر در ترمینال سرور با دسترسی "root" است:

bash <(curl -fsSL https://raw.githubusercontent.com/namedkenzo/namedICMP/main/install.sh)
