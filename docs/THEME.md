# تم named — نسخهٔ 0.2.1

هویت پنل از نام named ساخته شده: نشان اختصاصی n، لوگوتایپ named با نقطهٔ طلایی و معرفی کوتاه ICMP. رابط تیره ذغالی با طلایی شامپاینی و رابط روشن عاجی با تأکید طلایی تیره دارد. صفحهٔ ورود، خانه، جدول کاربران، خروجی‌ها و اطلاعات اتصال از یک مجموعه رنگ و آیکن استفاده می‌کنند.

صفحهٔ ورود حلقه‌های سیگنال دارد؛ بازشدن صفحات و فرم‌ها کوتاه و نرم است و روی دکمه‌های اصلی حرکت ظریف نور دیده می‌شود. حرکت‌ها برای نمایش داده‌های شبکه جعل نمی‌شوند. نمودار فقط نمونه‌های واقعی ثبت‌شده در مرورگر را نشان می‌دهد؛ با تازه‌سازی صفحه، تاریخچه از نو شروع می‌شود.

فونت‌های متغیر Manrope و Vazirmatn به‌صورت محلی داخل باینری سرو می‌شوند. هیچ درخواست CDN برای فونت یا آیکن لازم نیست. مجوز فونت‌ها در `docs/fonts/` و `THIRD_PARTY_NOTICES.md` آمده است؛ طرح نشان و آیکن‌ها جزو کد اصلی پروژه‌اند.

فارسی راست‌به‌چپ و انگلیسی چپ‌به‌راست، حالت روشن/تیره، فوکوس کیبورد، منوی موبایل و فرم قابل‌اسکرول پشتیبانی می‌شوند. تنظیم کاهش حرکت سیستم (`prefers-reduced-motion`) انیمیشن‌ها را خاموش می‌کند. هنگام پنهان‌شدن تب، حرکت‌های CSS متوقف می‌شوند. حلقه‌های پیوسته فقط در صفحهٔ ورود هستند.

برای اعمال روی نصب قبلی، ZIP جدید را باز کنید، از پوشهٔ جدید `sudo bash install.sh` را اجرا و گزینهٔ ۲، Update را انتخاب کنید. پس از Update صفحه را تازه‌سازی کنید؛ در صورت کش‌بودن ظاهر قبلی، hard refresh انجام دهید. انتخاب زبان و تم قبلی شما حفظ می‌شود.
